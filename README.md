# Monoplegia

Клиентский мод для Fabric / Minecraft Java 26.3: переключает возможность использовать обычные факелы и фонари из второй руки. Удобен при игре с Dynamic Lights: предмет остаётся в руке, но случайная установка блокируется.

**Статус: MVP, 0.1.0.** Предназначен для 26.3; более новые минорные версии требуют отдельной проверки и сборки. Автоматическое определение Dynamic Lights не требуется и не выполняется. Мод не добавляет динамическое освещение самостоятельно.

## Установка и использование

1. Установите Minecraft 26.3, Java 25+ и Fabric Loader 0.19.5+.
2. Положите собранный `build/libs/monoplegia-0.1.0-mvp.jar` и Fabric API для 26.3 в папку `mods` клиента.
3. По желанию установите Mod Menu 21.0.0 для доступа к настройкам.
4. Нажмите **G**, чтобы запретить или разрешить установку света из второй руки. В списке клавиш действие называется «Переключить режим запрета». Клавиша меняется в «Настройки → Управление → Назначение клавиш → Monoplegia».

По умолчанию установка **разрешена**, уведомления показываются над хотбаром. Повторное нажатие разрешает установку. Выбор сохраняется между запусками. Уведомление: «Установка факелов и фонарей разрешена/запрещена»; последнее слово зелёное при разрешении и красное при запрете. Для работы на сервере достаточно установить мод на клиент.

Фильтр содержит ровно `minecraft:torch` и `minecraft:lantern`. Факелы можно блокировать и при установке на стену. Основная рука, душевные, редстоун- и медные варианты, предметы других модов и все прочие предметы сохраняют обычное поведение. Действие основной руки обрабатывается Minecraft первым: например, открытие сундука обычным кликом остаётся доступно. При включённом запрете отменяется весь клик по блоку выбранным предметом **из второй руки**, в том числе при приседании. В воздухе у обычных факелов и фонарей нет действия установки.

## Настройка

В Mod Menu откройте Monoplegia → настройки: доступны переключение установки и выбор уведомлений (чат / над хотбаром). Экран показывает название мода по центру сверху и кнопку «Готово» по центру снизу; каждая настройка содержит заголовок, переключатель и кнопку «Сброс» в одной строке, а ниже — краткое пояснение только выбранного значения, которое обновляется при переключении и сбросе. Сброс применяется отдельно к выбранной настройке и сохраняется сразу. Значения по умолчанию: установка разрешена, уведомления над хотбаром. Mod Menu необязателен, других библиотек интерфейса не нужно.

Игровые настройки хранятся в стандартном для Fabric файле `config/monoplegia.json`:

```json
{
  "blockOffhandLights": false,
  "notification": "ACTION_BAR"
}
```

`notification`: `ACTION_BAR` или `CHAT`. Вручную редактируйте файл при закрытой игре. Повреждённая конфигурация копируется в `monoplegia.json.invalid`, затем применяются значения по умолчанию. Ошибки сохранения записываются в журнал; настройка продолжает действовать в текущем сеансе.

Локальные параметры окружения сборки — в `.env` (образец `.env.example`, файл исключён из git). Игровая конфигурация использует JSON, чтобы работать с обычным профилем Minecraft и Mod Menu. Версии зависимостей зафиксированы в `gradle.properties`.

## Разработка

Нужен JDK 25 и доступ к Maven/Mojang для первой сборки. Gradle Wrapper скачает Gradle 9.6.0 автоматически.

```bash
cp .env.example .env
./scripts/build.sh
./scripts/build.sh runClient
./scripts/build.sh test
```

Готовый мод: `build/libs/monoplegia-0.1.0-mvp.jar`. Файл с суффиксом `-sources.jar` предназначен для разработки, его не нужно устанавливать в игру.

Документация: [архитектура](docs/architecture.md), [функции](docs/features.md), [проверки](docs/testing.md).

Версии и API сверялись с [Fabric 26.3](https://fabricmc.net/2026/09/15/263.html), [официальным шаблоном](https://github.com/FabricMC/fabric-example-mod/tree/26.3), [Mod Menu](https://github.com/TerraformersMC/ModMenu/releases/tag/v21.0.0).

Для релиза замените белую иконку-заглушку `src/main/resources/assets/monoplegia/icon.png` (128 × 128). Название, краткое и полное описание в Mod Menu переведены на русский и английский.
