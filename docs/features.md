# Функции

- Обычные факелы и фонари: разрешение установки по умолчанию.
- G: единый переключатель запрета обоих предметов из второй руки; переназначается средствами Minecraft.
- Точный список: minecraft:torch, minecraft:lantern; отсутствуют широкие теги и сопоставление по имени.
- Статус при переключении над хотбаром, опционально в чате: «Установка факелов и фонарей разрешена/запрещена». Только последнее слово окрашено в зелёный/красный.
- Сохранение состояния и способа уведомлений в config/monoplegia.json.
- Необязательная страница настроек Mod Menu без Cloth Config: название Monoplegia по центру сверху, кнопка «Готово» по центру снизу, две строки с заголовком, переключателем и отдельным сбросом; пояснения только выбранных значений под заголовками, обновляемые при переключении и сбросе.
- Сброс установки возвращает разрешение, сброс уведомлений — вывод над хотбаром. Кнопка сброса неактивна при значении по умолчанию.
- Русские и английские название/описания для Mod Menu; белая иконка-заглушка 128 × 128 для замены перед релизом.
- Русская и английская локализации.
- Не меняет предмет в руке, его компоненты, яркость или поведение Dynamic Lights.

Не реализованы: отдельные переключатели двух предметов, настраиваемый список предметов, автоматическое обнаружение освещения, постоянный HUD-индикатор. Для текущего сценария они не требуются.
