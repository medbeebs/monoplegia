# Проверки

## Автоматические

`./scripts/build.sh build` компилирует основной код и клиент, выполняет JUnit-тесты и создаёт JAR. Тесты PlacementPolicy проверяют включение/выключение, обе руки, обычные/душевные/редстоун-/медные варианты, щит, строительные блоки и предметы стороннего namespace.

Проверено 2026-10-25: `build --no-daemon` завершился успешно на Java 25.0.3; основной код и клиент скомпилированы, JAR упакован, 2 JUnit-теста прошли без ошибок. После правок MVP повторная offline-сборка успешна; проверены версия 0.1.0-mvp, упаковка иконки и паритет ключей RU/EN в готовом JAR. Дополнительно проверен обработчик Fabric API 0.163.0+26.3: FAIL отменяет useItemOn без отправки пакета установки.

## Игровая проверка перед выпуском

Эта матрица требует реального клиента и пока не считается выполненной:

1. Новый профиль без конфигурации: факел и фонарь во второй руке ставятся на пол, факел также на стену, фонарь подвешивается.
2. Нажать G: статус «запрещена», установки обоих предметов нет, количество предметов не уменьшается. Повторить с Shift и удерживаемой ПКМ.
3. Нажать G повторно: размещение восстановлено; проверить точный текст уведомления и зелёный/красный цвет только последнего слова в обоих каналах. В назначении клавиш проверить подпись «Переключить режим запрета»; переназначить клавишу и проверить.
4. При запрете проверить основную руку, душевные и редстоун-факелы, душевные фонари, медные варианты, щит, еду, блоки.
5. При факеле/фонаре во второй руке основной рукой открыть сундук/дверь и использовать верстак; повторить с пустой основной рукой. Учесть: если действие дошло именно до запрещённой второй руки, весь её клик отменяется.
6. Перезапустить клиент: состояние и канал уведомлений сохраняются.
7. Mod Menu: проверить русское описание и белую иконку; открыть настройки из главного меню и мира. Убедиться, что название Monoplegia центрировано сверху, «Готово» центрировано у нижнего края, заголовки стоят слева в соответствующих строках с переключателем/сбросом. Под каждым заголовком видно описание только выбранного значения; оно сразу меняется при переключении и сбросе. Проверить отсутствие пересечений при GUI scale и минимальном размере окна. В описании Mod Menu нет конкретной клавиши, переназначения и уведомлений. Изменить обе опции, сбросить каждую отдельно (установка разрешена / над хотбаром); при значении по умолчанию кнопка сброса неактивна. Вернуться назад. Удалить Mod Menu и проверить запуск и G.
8. Повторить размещение на отдельном Fabric/vanilla-сервере без серверной установки Monoplegia: блок не должен появляться после синхронизации.
9. С совместимым Dynamic Lights: убедиться, что освещение от предмета продолжает работать, а установка блокируется.
10. Проверить spectator, creative, survival и повреждённый JSON (резервная копия, отсутствие падения).

Unit-тесты не доказывают поведение пакетов или совместимость интерфейса в игре; для этого нужны пункты выше.
