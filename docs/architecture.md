# Архитектура

Java 25, Minecraft 26.3 (официальные необфусцированные имена), Fabric Loom 1.17.7, Gradle Wrapper 9.6.0, Fabric API 0.163.0+26.3. Только клиентский entrypoint, серверная установка не требуется.

- `PlacementPolicy` — независимый от Minecraft фильтр: запрет включён, вторая рука, точный ID обычного факела или фонаря.
- `MonoplegiaClient` — регистрация G через KeyMappingHelper, обработка на END_CLIENT_TICK, UseBlockCallback и уведомления.
- `MonoplegiaConfig` — чтение/сохранение JSON через встроенный в Minecraft Gson, резервная копия некорректного файла, журнал ошибок.
- `MonoplegiaScreen` — кнопки и текстовые виджеты стандартного интерфейса Minecraft. Заголовок экрана центрируется по измеренной ширине текста, кнопка «Готово» привязана к нижнему краю. Для StringWidget используются явные координаты и размеры: короткий конструктор (int, int, Component, Font) в 26.3 принимает ширину и высоту, а не позицию. Описания текущих значений обновляются в refresh() при переключении и сбросе; у каждой настройки собственная кнопка сброса, использующая константы DEFAULT_* из MonoplegiaConfig.
- `MonoplegiaModMenu` — необязательный entrypoint Mod Menu. Без Mod Menu этот класс не загружается.

UseBlockCallback возвращает FAIL только для выбранных предметов во второй руке на клиенте и только при включённом запрете. Это останавливает отправку пакета взаимодействия: отмена исключительно на этапе локального рендера или использования ItemStack не гарантировала бы блокировку установки сервером. Для остальных случаев возвращается PASS. Spectator исключён.

Основная рука обрабатывается ванилью раньше второй. Фильтр отменяет всё взаимодействие с блоком подходящим предметом во второй руке; это намеренно не механизм серверного контроля. Не используются mixin, сетевые каналы и API конкретных модов динамического освещения.

Граница совместимости в fabric.mod.json — ~26.3. Заявлять универсальную совместимость с любыми будущими выпусками нельзя: при обновлении следует проверить API, изменить зависимости и повторить сборку и игровую матрицу.
