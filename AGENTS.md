# Monoplegia

Клиентский Fabric-мод, Java 25, Minecraft 26.3. Статус: MVP. Работаем в текущем репозитории; subagents не требуются.

Контекст:
- [README.md](README.md): назначение, установка, настройка, сборка и статус.
- [docs/architecture.md](docs/architecture.md): компоненты, отмена сетевого взаимодействия, границы совместимости.
- [docs/features.md](docs/features.md): точная область фильтра и функции.
- [docs/testing.md](docs/testing.md): автоматические проверки и игровая матрица.

Сборка: `./scripts/build.sh build`, dev-клиент: `./scripts/build.sh runClient`. Не расширять список предметов тегами: требуются только обычные vanilla torch/lantern, только offhand. По умолчанию установка разрешена. Mod Menu — необязательная зависимость. Скрипты — scripts/, временные — scripts/tmp/ (gitignore). Локальное окружение — .env, пример — .env.example. Не заявлять игровую проверку без запуска клиента; перед beta/sigma применять OpenSpec для доработок.

Любой новый проект начинается как MVP. Изменять статус только с явного разрешения пользователя. Публиковать код в remote git разрешено только для alpha и выше. Текущий MVP установлен по прямому запросу пользователя.
